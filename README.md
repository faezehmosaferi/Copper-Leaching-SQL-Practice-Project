# Copper-Leaching-SQL-Practice-Project

Advanced PostgreSQL exercises based on tank leaching process data.

## Setup
1. Run `schema.sql` to create tables
2. Run `seed.sql` to insert sample data
3. Open files and run queries in pgAdmin

## Topics Covered
- Window Functions (RANK, AVG OVER)
- CTEs (Regular, Recursive)
- Aggregation (GROUPING SETS)
- Time Series (gap filling)
- Performance (Indexes, Materialized CTE)

## Requirements
- PostgreSQL 12+
- pgAdmin (optional)
